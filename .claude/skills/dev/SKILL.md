# /dev — 開發

## 參數

呼叫時傳入的 args 就是 `<domain>`（例：`passport`）。下文的 `<domain>` 一律代換成它。
args 沒有給 domain 時，先問使用者，不要猜。

## 步驟

1. 確認：
   - 03 本版次為「已核准」
   - 02 的環境就緒檢查全部就緒

   有未就緒項目時停下來列給我，除非我明確同意例外開工；同意的內容要寫進 02 的待決事項。
2. 01～03 本版次修訂紀錄的狀態改為「開發中」，commit。
3. 依 03 開發項目清單的順序，**一次派一個** implementer，直接在目前工作目錄修改。
   - 派工內容寫明：D-n、03 與 01 的路徑、是否有例外開工的同意
   - 只有標為「可平行」、且檔案互不重疊的項目，才同時派
4. 每個項目完成後，主線要：
   - 檢查 `git diff`，只能包含該項目列出的檔案
   - 勾選 03 開發項目清單的「完成」欄
   - commit：`feat(<domain>): D-n <項目名>`
5. 任一 implementer 回報「文件矛盾」或「阻塞」時，停止派工並回報給我。

全部完成後停下來。下一步是 `/qa <domain>`。
