# /qa — 測試驗收與上線結案

## 參數

呼叫時傳入的 args 就是 `<domain>`（例：`passport`）。下文的 `<domain>` 一律代換成它。
args 沒有給 domain 時，先問使用者，不要猜。

## 步驟

1. 確認 03 開發項目清單全部勾選完成。
2. 找出本版次的基準 commit，寫進派工內容。基準 commit 是上一個版次上線的 commit；如果這是第一版，就用 01 本版次核准前的最後一個 commit。
3. 派一個**新的** qa-reviewer，撰寫或更新 `docs/<domain>/04-測試報告.md`。
4. 回報後呈現給我：結論、必須修正的問題、未執行項目。
   - 不通過：把問題交回 implementer 修正，修完後再派**另一個新的** qa-reviewer。不要沿用同一個。
   - 通過且我確認後，主線要：
     - 把 01～04 本版次修訂紀錄的狀態改為「已上線」
     - 清除 01～03 的 `〔vX.Y 新增〕`、`〔vX.Y 修改〕` 標記，保留「刪除」標記
     - commit：`docs(<domain>): vX.Y 上線`
